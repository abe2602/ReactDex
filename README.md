# ReactDex
Pokedex made using React for learning purpose

## Features
- Displays a grid of Pokemon from the first generation (151 Pokemon)
- Search functionality to find Pokemon by name
- Detailed view of selected Pokemon with stats and attributes
- Responsive design with sticky Pokemon details

## Technologies Used
- React 18
- TypeScript
- Vite
- ESLint for code quality
- PokeAPI for Pokemon data

## Getting Started
1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
